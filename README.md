# GTAVI-Discord

Пока вы играете в **GTA V**, в Discord у вас отображается **Grand Theft Auto VI** — как будто вы уже играете в шестую часть.

Только игра и время. Никаких «где нахожусь», «чем занят», статистики и прочего шума — ровно такой же вид активности, как у обычной игры.

```
┌──────────────────────────────────────────┐
│  Играет в Grand Theft Auto VI            │   ← режим pc
│  ┌──────┐                                │
│  │      │  Grand Theft Auto VI           │
│  │ икон │  2:14:07                       │
│  └──────┘                                │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│  Играет в Grand Theft Auto VI (PlayStation) │   ← режим playstation
│  ┌──────┐                                │
│  │      │  Grand Theft Auto VI           │
│  │ икон │  2:14:07            [PS-бейдж] │
│  └──────┘                                │
└──────────────────────────────────────────┘
```

---

## Что умеет

* **Два режима отображения** — обычный (`pc`) и «консольный» (`playstation`), переключаются на ходу одной командой.
* **Работает в фоне** — без окна, без трея, без служб. Типичное потребление: **0 % процессора** и **1–3 МБ оперативной памяти**.
* **Сам замечает игру** — опрашивает список процессов раз в 5 секунд (настраивается), сам ставит активность при запуске игры и убирает при выходе.
* **Сам переподключается** — перезапустили Discord, он подхватит соединение и вернёт активность.
* **Автозапуск** — `--install`, и программа стартует вместе с Windows.
* **Ноль зависимостей** — один exe на C, ~250 КБ, без .NET, Node.js, Python и без Visual C++ Redistributable (CRT вкомпилирован статически).

## Быстрый старт (5 минут)

### 1. Скачать

Возьмите `GTAVI-Discord-windows-x64.zip` из раздела **Releases** (или соберите сами — см. [«Сборка»](#сборка-из-исходников)) и распакуйте в любую постоянную папку, например `C:\Games\GTAVI-Discord\`.

### 2. Создать приложение в Discord

Активность в Discord берёт название и картинку из *приложения* Discord, поэтому своё приложение нужно создать один раз:

1. Откройте <https://discord.com/developers/applications> → **New Application**.
2. Имя — ровно `Grand Theft Auto VI` (**это имя увидят друзья**, оно и станет названием «игры»).
3. На странице **General Information** скопируйте **Application ID** (длинное число).
4. Слева откройте **Rich Presence → Art Assets**:
   * **Add Image(s)** → загрузите вашу иконку (лучше квадратную, 1024×1024 PNG). Ключ ассета (поле под картинкой) — `gta6`.
   * хотите бейдж PlayStation в режиме `playstation` — загрузите вторым файлом логотип PS с ключом `ps5`.
   * нажмите **Save Changes** и подождите пару минут, пока ассеты разойдутся по CDN.

> Иконка из шага 4 необязательна: если поле `large_image` в настройках оставить пустым, Discord покажет иконку самого приложения (её тоже можно задать в General Information).

### 3. Вписать Application ID

Запустите `GTAVI-Discord.exe`. При первом запуске он создаст рядом с собой файл `config.ini` и покажет подсказку с путём к нему. Откройте файл блокнотом и заполните:

```ini
[discord]
client_id = 1234567890123456789   ; ← сюда Application ID из шага 2
mode = pc
```

### 4. Выключить автоматическую активность GTA V в Discord

Иначе Discord покажет **две** игры: настоящую GTA V (он её распознаёт сам) и нашу GTA VI.

Discord → **Настройки пользователя → Игровая активность → Зарегистрированные игры** → найдите `Grand Theft Auto V` → выключите переключатель.

Заодно проверьте, что в **Настройки → Конфиденциальность активности** включено «Демонстрировать текущую активность в качестве статуса».

### 5. Запустить

Снова запустите `GTAVI-Discord.exe` — окно не появится, программа уйдёт в фон. Запустите GTA V: через пару секунд в профиле появится Grand Theft Auto VI с таймером. Закрыли игру — активность исчезла.

Чтобы программа стартовала вместе с системой:

```bat
GTAVI-Discord.exe --install
```

## Режимы

| Режим | Как выглядит | Что отправляется |
|---|---|---|
| `pc` | «играет в Grand Theft Auto VI» и таймер | `type: 0`, `timestamps.start`, картинка |
| `playstation` | то же + плашка/бейдж PlayStation | всё выше + `platform: "ps5"` + маленькая иконка PS |

Переключение на ходу (программа должна быть запущена):

```bat
GTAVI-Discord.exe --mode playstation
GTAVI-Discord.exe --mode pc
GTAVI-Discord.exe --mode toggle      :: переключить в другой
```

Режим сохраняется в `config.ini`, так что после перезапуска останется тем же. Можно переключать и вручную — правкой `mode` в файле (применяется при следующем запуске).

### Про плашку PlayStation

В объекте активности Discord есть поле `platform` (значения `desktop`, `ps4`, `ps5`, `xbox` — это то, чем Discord помечает сессии с консолей). В режиме `playstation` программа отправляет `"platform": "ps5"`.

Честное предупреждение: поле не описано в публичной документации локального RPC (оно есть в схеме клиента, а RPC принимает дополнительные поля), поэтому **гарантировать плашку «Playing on PlayStation» на 100 % нельзя** — это решает клиент Discord, и в разных версиях поведение может отличаться. Что гарантированно видно всегда — картинка игры, название, таймер и, если вы задали `small_image`, бейдж с логотипом PlayStation в углу картинки. Если плашка у вас не появляется, поставьте `platform = none` и пользуйтесь бейджем: выглядит почти так же.

Значение настраивается в секции `[playstation]`:

```ini
[playstation]
platform = ps5     ; ps5 | ps4 | xbox | none
```

## Команды

| Команда | Что делает |
|---|---|
| `GTAVI-Discord.exe` | запустить в фоне (второй запуск просто ничего не сломает) |
| `--console` | запустить с окном консоли и логом на экране |
| `--status` | показать состояние: режим, подключение к Discord, идёт ли игра |
| `--mode pc\|playstation\|toggle` | переключить режим |
| `--stop` | корректно остановить (активность будет убрана) |
| `--install` / `--uninstall` | добавить/убрать из автозапуска |
| `--config PATH` | использовать другой файл настроек |
| `--version`, `--help` | версия и справка |

Пример:

```bat
> GTAVI-Discord.exe --status
running mode=playstation discord=connected playing=yes since=1763558400
```

Все команды общаются с уже запущенной программой через локальный канал (named pipe на Windows, unix-сокет на Linux) — это занимает микросекунды и не требует прав администратора.

## Настройки (`config.ini`)

Файл создаётся автоматически при первом запуске рядом с exe. Если exe лежит в `Program Files` (куда писать нельзя), файл будет создан в `%LOCALAPPDATA%\GTAVI-Discord\config.ini`.

```ini
[discord]
client_id =                  ; Application ID приложения Discord (обязательно)
mode = pc                    ; pc | playstation

[activity]
large_image = gta6           ; ключ картинки; пусто = иконка приложения
large_text = Grand Theft Auto VI
small_image =                ; ключ маленькой иконки-бейджа; пусто = без бейджа
small_text = PlayStation 5

[playstation]
platform = ps5               ; ps5 | ps4 | xbox | none

[detection]
poll_ms = 5000               ; период опроса процессов, мс (500–60000)
processes = GTA5.exe, GTA5_Enhanced.exe, FiveM.exe

[log]
level = info                 ; error | warn | info | debug
```

* `processes` — имена процессов, которые считаются «игрой». Регистр не важен, `.exe` можно не писать. По умолчанию: обе версии GTA V (обычная и Enhanced) и FiveM. Можно добавить RAGE MP, RedM и что угодно ещё.
* `poll_ms` — компромисс между отзывчивостью и расходом CPU. 5000 мс = активность появляется за ≤5 секунд и процессор практически не тратится. 1000 мс — быстрее, но всё равно незаметно.
* Статистики (`details`, `state`, `party`) в активности нет намеренно: она не меняется, а значит программе не нужно ничего пересылать во время игры.

Лог пишется в `presence.log` рядом с `config.ini` (обрезается при размере больше 1 МБ).

## Расход ресурсов

Замер на Linux (Release-сборка, игра запущена, активность опубликована):

```
VmRSS:     904 kB
Threads:   2
CPU:       0 тиков за 10 секунд (ниже разрешения счётчика)
```

На Windows цифры немного выше за счёт системных библиотек — порядка 1,5–2,5 МБ. Процессор не тратится: программа спит на событии, просыпается 5 раз в секунду на один дешёвый вызов и раз в `poll_ms` снимает список процессов.

## Сборка из исходников

Нужен только компилятор C11 и CMake ≥ 3.16. Никаких внешних библиотек.

**Windows (MSVC / Visual Studio Build Tools):**

```bat
cmake -B build -A x64 -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
:: build\Release\GTAVI-Discord.exe
```

**Windows (MinGW-w64):**

```bat
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

**Linux:**

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure          # юнит-тесты
cc -O2 -o /tmp/fake-discord tools/fake-discord.c
bash tests/e2e.sh build/GTAVI-Discord /tmp/fake-discord   # сквозной тест
```

Иконку exe можно задать, положив файл `assets/icon.ico` — CMake вкомпилирует его в ресурсы автоматически.

CI (GitHub Actions) собирает Windows- и Linux-версии, гоняет тесты и по тегу `v*` публикует релиз с архивами.

## Как это работает

1. **Поиск игры.** Раз в `poll_ms` программа снимает список процессов (`CreateToolhelp32Snapshot` на Windows, обход `/proc` на Linux) и сравнивает имена с `processes`. Хуков, чтения памяти и вмешательства в игру нет — это обычный список задач.
2. **Подключение к Discord.** Локальный RPC Discord — это именованный канал `\\.\pipe\discord-ipc-N` (`$XDG_RUNTIME_DIR/discord-ipc-N` на Linux), по которому ходят JSON-кадры `[opcode][length][payload]`. Программа делает `HANDSHAKE` с вашим `client_id`, дожидается `READY`, отвечает на `PING` и переподключается с задержкой, если Discord закрыли.
3. **Активность.** Отправляется один `SET_ACTIVITY`:

   ```json
   {"cmd":"SET_ACTIVITY","args":{"pid":1234,"activity":{
      "type":0,
      "timestamps":{"start":1763558400},
      "assets":{"large_image":"gta6","large_text":"Grand Theft Auto VI"},
      "platform":"ps5"
   }}}
   ```

   Таймер Discord считает сам от `start`, поэтому обновлять активность во время игры не нужно. При выходе из игры отправляется `"activity": null` — профиль становится чистым.
4. **Остановка.** `--stop` (или закрытие сессии) снимает активность и корректно закрывает канал.

Программа ничего не читает из игры, не требует токенов Discord, не логинится в ваш аккаунт и не отправляет данные никуда, кроме локального клиента Discord.

## Частые вопросы

**В профиле две игры — GTA V и GTA VI.**
Discord сам распознаёт `GTA5.exe`. Выключите `Grand Theft Auto V` в *Настройки → Игровая активность → Зарегистрированные игры*.

**Активность не появляется.**
1. `GTAVI-Discord.exe --status` — что он пишет?
2. `discord=connected` — если нет, запущен ли клиент Discord (не браузер, а приложение)?
3. `playing=yes` — если нет, добавьте имя процесса игры в `processes` (например, `PlayGTAV.exe`, если у вас своя сборка).
4. Включено ли «Демонстрировать текущую активность» в настройках Discord.
5. Посмотрите `presence.log` (уровень `debug` в `config.ini` даёт максимум подробностей).

**«Discord отклонил client_id».**
Неверный `client_id`: нужно именно *Application ID* из Developer Portal, а не Client Secret и не ID аккаунта.

**Иконка не отображается.**
Ассет должен быть загружен в *Rich Presence → Art Assets* того же приложения, а его ключ — совпадать с `large_image` (по умолчанию `gta6`). После загрузки подождите несколько минут.

**Можно ли так же «играть» в другую игру?**
Да: поменяйте имя приложения Discord, его иконку и `processes` в конфиге. Ограничений в коде нет.

**Нужны ли мой ник и ID Discord?**
Нет. RPC работает для того пользователя, под которым запущен клиент Discord на этой машине; никакие ID в настройках не нужны и никуда не передаются.

**Это нарушает правила Discord?**
Программа использует официальный локальный RPC-интерфейс (тот же, что у игр и музыкальных плееров) и ваш собственный аккаунт не трогает: ни токенов, ни автоматизации действий, ни самоботов. Активность — это то, что вы и так можете показать о себе.

## Структура репозитория

```
src/            исходники (C11, без зависимостей)
  common.c      время, строки, файлы, пути
  config.c      разбор и сохранение config.ini
  ipc.c         протокол Discord (named pipe / unix socket)
  presence.c    сборка активности и её состояние
  detect.c      поиск процесса игры
  control.c     канал управления (--stop/--status/--mode) и single instance
  wake.c        прерываемое ожидание
  log.c         лог
  main.c        CLI и главный цикл
tests/          юнит-тесты и сквозной тест с фальшивым Discord
tools/          fake-discord.c — подставной клиент Discord для тестов
.github/        CI: сборка Windows/Linux, тесты, релиз
assets/         сюда можно положить icon.ico для иконки exe
```
