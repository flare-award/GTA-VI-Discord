# assets/

Сюда можно положить `icon.ico` — иконку самой программы (exe).

Если файл `assets/icon.ico` существует, CMake автоматически вкомпилирует его в
ресурсы `GTAVI-Discord.exe` при сборке (в том числе в GitHub Actions), никаких
дополнительных действий не нужно.

Если файла нет, exe собирается со стандартной иконкой.

Важно: это иконка **программы** (в проводнике и на панели задач). Иконка
**игры** в активности Discord загружается не сюда, а в Discord Developer Portal
(Rich Presence → Art Assets, ключ `gta6`) — см. README.

Требования к `icon.ico`: обычный ICO с размерами 16/32/48/256, до ~200 КБ.
